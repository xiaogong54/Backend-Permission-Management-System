# 电商后台管理系统（商家管理端）· 设计概览

> 项目代号 `mall-admin-web` ｜ 定位：面向中小型电商商家的轻量化后台 ｜ 范围：**仅商家管理端**，不做 C 端商城
> 本文是汇总版，只给结论；细节按需再展开。

---

## 1. 技术栈

| 层 | 选型 |
| --- | --- |
| 前端 | Vue 3 + TypeScript + Vite + Element Plus + Pinia + ECharts |
| 后端 | NestJS + TypeScript + Prisma + JWT + Redis |
| 数据库 | MySQL 8.0（utf8mb4） |
| 工程化 | pnpm workspace 单仓 + Docker Compose + ESLint/Prettier + Swagger |

## 2. 数据模型：19 张表 / 4 个域

| 域 | 表 |
| --- | --- |
| 系统权限 `sys_` | `sys_admin`、`sys_role`、`sys_permission`、`sys_admin_role`、`sys_role_permission`、`sys_operation_log`、`sys_file` |
| 商品 `pms_` | `pms_category`、`pms_spec`、`pms_spec_value`、`pms_spu`、`pms_spu_image`、`pms_sku`、`pms_sku_spec_value` |
| 用户 `ums_` | `ums_user`、`ums_user_address` |
| 订单 `oms_` | `oms_order`、`oms_order_item`、`oms_order_status_log` |

**三条核心关系**

| 关系 | 基数 | 关键点 |
| --- | --- | --- |
| SPU — SKU | 1:N | 价格库存挂 SKU；SPU 上的价格区间/总库存是聚合冗余字段 |
| 订单 — 订单明细 | 1:N | 明细存**商品全字段快照**，商品改名改价不影响历史订单 |
| 用户 — 角色 — 权限 | N:M | 两张中间表 `sys_admin_role`、`sys_role_permission` |

**四条统一约定**：金额用 `DECIMAL`；时间用 `DATETIME`（不用 `TIMESTAMP`）；主数据用 `deleted_at` 软删除；**不使用数据库外键**，删除策略由 Service 层逐条保证。

---

## 3. 权限模型：三级权限，一份权限清单

| 粒度 | 落地方式 |
| --- | --- |
| 页面级 | `sys_permission.type=2`（菜单）→ 后端按角色返回菜单树 → 前端动态注册路由 |
| 按钮级 | `type=3`（按钮）→ 前端 `v-permission` 指令控制显隐 |
| 接口级 | **与按钮共用同一个 `code`** → 后端 `@RequirePermission('product:spu:create')` 守卫拦截 |

- 权限码规范：`模块:资源:动作`，如 `product:spu:batch-status`、`order:order:export`。
- 菜单/接口**统一建模在一张树表**，用 `type`（1 目录 / 2 菜单 / 3 按钮 / 4 接口）区分。
- 超级管理员走**通配符 `*`**，不落关联表 —— 新增权限点无需回头给超管补授权。

## 4. 接口总览（RESTful，前缀 `/api/v1`）

| 模块 | 主要端点 | 端点数 |
| --- | --- | --- |
| 认证 `/auth` | `captcha`、`login`、`logout`、`profile`、`menus`、`refresh`、`password` | 7 |
| 系统 `/admins` `/roles` `/permissions` `/logs` | 管理员/角色/菜单 CRUD、分配角色与权限、重置密码、操作日志查询与导出 | 26 |
| 商品 `/product/*` | 二级分类、规格与规格值、SPU（含上下架与批量）、SKU（含库存调整）、图片 | 24 |
| 订单 `/orders` | 列表（多条件）、详情、发货、取消、完成、备注、Excel 导出 | 7 |
| 用户 `/users` | 列表、详情、状态管控、收货地址 | 5 |
| 看板 `/dashboard` | 指标卡片、销售额趋势、订单量趋势、商品销量 TOP10、用户消费 TOP10 | 5 |
| 公共 `/files` `/profile` | 文件上传、个人中心 | 4 |

**统一响应体**：`{ code, message, data, traceId }`，HTTP 状态码语义化；分页统一 `{ list, total, page, pageSize }`；业务错误码分段（1xxxx 通用 / 2xxxx 认证 / 3xxxx 商品 / 4xxxx 订单 / 5xxxx 用户）。

## 5. 订单状态机

```
1 待付款 ──支付──► 2 待发货 ──发货──► 3 已发货 ──确认收货──► 4 已完成
   │                  │
   └──取消/超时──► 5 已取消 ◄──取消（仅后台）
```

- 用**声明式转移表**实现，未定义的事件一律拒绝，新增状态只改一处。
- 每次跃迁在**同一事务内**完成：乐观锁更新订单 → 写 `oms_order_status_log` → 调整 SKU 库存/销量 → 累加用户消费统计。
- 库存并发用**单条带条件 UPDATE**（`WHERE stock - locked_stock >= n`），影响行数为 0 即库存不足 —— 一条 SQL 同时解决超卖与并发，不需要分布式锁。
- 订单状态并发用 `version` **乐观锁**。

## 6. 关键设计决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 订单商品信息 | 全字段快照 | 正确性要求，非优化 |
| SPU 价格区间/总库存 | 冗余，仅由 SKU 变更触发重算 | 列表页免 JOIN 免聚合 |
| 用户累计消费 | 写时更新（订单完成时） | 看板高频读、订单低频写 |
| 订单删除 | 物理不开放，只允许"取消" | 财务凭证不可删 |
| 被订单引用的数据 | 只能停用/下架，不能删 | 杜绝"删商品导致订单打不开" |
| 商品模糊搜索 | `LIKE '%kw%'`，接受全扫 | 万级数据量够用；百万级再上全文索引/ES |

## 7. 视觉风格与交互动效

> 定稿原型：[`原型.html`](原型.html)（零依赖单文件，浏览器直接打开）。本节是该原型的规范化沉淀，**两者取值必须一致**。

### 7.1 风格定位

**清爽专业蓝**：浅色内容区 + 深色侧边栏，形成层次。主色贴近 Element Plus 默认蓝，通过 SCSS 变量覆盖接入，定制成本最低。

### 7.2 设计令牌

**色板**

| 用途 | 取值 |
| --- | --- |
| 品牌主色 | `#2563eb` |
| 主色 hover / active | `#1d4ed8` / `#1e40af` |
| 主色浅底（选中态、标签底） | `#eff6ff` — `#dbeafe` |
| 成功 / 警告 / 危险 | `#16a34a` / `#d97706` / `#dc2626` |
| 侧边栏底 / 选中高亮 | `#0f172a` / `rgba(37,99,235,.18)` |
| 文字四级 | `#0f172a` 标题、`#334155` 正文、`#64748b` 次要、`#94a3b8` 占位 |
| 边框 / 分隔线 | `#e2e8f0` / `#f1f5f9` |
| 页面底 / 卡片底 | `#f5f7fa` / `#ffffff` |

**尺寸阶梯**

| 项 | 取值 |
| --- | --- |
| 字号 | 12 / 13 / 14 / 16 / 20 / 24 / 30 |
| 间距 | 4 的倍数：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 |
| 圆角 | 4 输入框内元素、6 小控件、8 按钮与输入框、12 卡片、16 弹窗、全圆 标签与头像 |
| 阴影 | 卡片 `0 1px 2px rgba(15,23,42,.05)`、悬浮 `0 4px 12px rgba(15,23,42,.08)`、浮层 `0 12px 32px rgba(15,23,42,.12)`、模态 `0 24px 56px rgba(15,23,42,.16)` |
| 字体 | 中文 PingFang SC / 微软雅黑；数字用 Inter 并启用 `tabular-nums`（表格数字对齐）；编码、订单号用等宽 |
| 布局尺寸 | 侧边栏 236px（折叠 64px）、顶栏 56px、标签栏 40px |

### 7.3 动效规范

**时长四档**

| 档位 | 用途 |
| --- | --- |
| 150ms | 颜色 / 边框 / 透明度等即时反馈（hover、focus） |
| 220ms | 小容器开合（下拉面板、字段错误滑入） |
| 320ms | 布局位移（侧边栏折叠、路由切换、标签指示条） |
| 480ms | 整屏级过渡（登录页 ↔ 主框架） |

**缓动三种**：标准 `cubic-bezier(.4,0,.2,1)`（进出对称，默认）；入场 `cubic-bezier(0,0,.2,1)`（减速）；回弹 `cubic-bezier(.34,1.56,.64,1)`（仅用于状态切换与 Toast 入场）。

**逐场景清单**

| 场景 | 效果 |
| --- | --- |
| 路由切换 | 内容区淡入 + 上移 10px，320ms 减速 |
| 列表 / 卡片入场 | 逐个淡入上移，60ms 步进，最多 6 项 |
| 指标数字 | easeOutExpo 滚动到目标值，900ms |
| 侧边栏折叠 | 宽度 320ms 过渡；文字与箭头让位，图标在 64px 内居中；折叠态悬停出浮动提示 |
| 子菜单展开 | `grid-template-rows` 0fr→1fr 高度自适应；箭头旋转 90°；手风琴同时只展开一个 |
| 菜单激活 | 左侧 3px 指示条 `scaleY` 生长，回弹缓动 |
| 标签页切换 | 底部指示条平移而非消失重现；关闭按钮仅 hover / 激活时淡入 |
| 按钮 | hover 上浮 1px 并加深阴影；active 下压回位；loading 文字淡出、转圈淡入 |
| 表单校验 | 字段错误从上方滑入；整体失败时卡片左右抖动 480ms |
| 数据加载 | 骨架屏 shimmer；加载完成替换为内容 |
| 提示消息 | 顶部回弹滑入，3s 后上移淡出，底部进度条可视化剩余时间 |
| 登录 → 控制台 | 登录页缩放淡出 → 主框架淡入，480ms |

### 7.4 强制约束

- **换风格只改令牌**：颜色、圆角、阴影、时长一律走 CSS 变量 / Element Plus SCSS 变量，组件样式里不得出现魔数。
- **尊重 `prefers-reduced-motion`**：系统开启「减少动态效果」时全站动画降级为瞬时，保留状态变化、去掉位移与缩放。
- **键盘可达**：统一用 `:focus-visible` 提供焦点环，鼠标点击不出现光晕；侧边栏折叠支持 `Ctrl/Cmd + B`。
- **不用转圈表达加载**：列表与卡片一律骨架屏，仅按钮等微交互用转圈。
- **动效服务于信息层级**：位移不超过 10px、缩放不超过 1.05，避免大幅动效拖慢后台的高频操作。

```

├─ apps/
│  ├─ server/             # NestJS
```
